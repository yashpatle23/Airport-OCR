# Airport OCR Research Artifacts

These documents capture completed research work for the VOBL airport-chart extraction study. They are non-operational and must not be treated as authoritative aeronautical data.

- [Enterprise airport-chart extraction research](research/ENTERPRISE_AIRPORT_CHART_EXTRACTION_RESEARCH.md) — architecture, extraction, validation, search, and delivery recommendations.
- **Phase 0 — blocked:** governance artifacts are prepared, but exit is blocked by missing original PDF bytes/hash, unresolved source rights, and unassigned accountable owners. See the [Phase 0 exit report](phase-0/PHASE_0_EXIT_REPORT.md).
- **Phase 1 — provisional/partially complete:** deterministic normalization and benchmark artifacts are available, while PDF/OCR/CV extraction and complete taxiway/holding-position work remain blocked. See the [Phase 1 discovery benchmark report](phase-1/PHASE_1_DISCOVERY_BENCHMARK_REPORT.md) and [Phase 1 exit report](phase-1/PHASE_1_EXIT_REPORT.md).

The code at [phase-1/scripts/normalize_and_validate.py](phase-1/scripts/normalize_and_validate.py) is preserved as historical benchmark code, not production application code.
